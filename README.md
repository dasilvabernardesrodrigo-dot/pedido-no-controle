# Pedido no Controle

Landing page responsiva do produto digital **Pedido no Controle**, pronta para hospedagem na Vercel.

## Publicar na Vercel

1. Importe este repositório na Vercel.
2. Em **Framework Preset**, escolha **Other**.
3. Não preencha comando de build.
4. Use `.` como diretório de saída, caso a Vercel solicite.
5. Clique em **Deploy**.

O botão de compra já aponta para o checkout oficial na Cakto.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: identidade visual e responsividade.
- `script.js`: animações leves, FAQ e preservação de UTMs.
- `assets/`: logo, mockup e prévias do produto.

## Observação

Site estático sem dependências ou etapa de build. Funciona abrindo `index.html` localmente ou em qualquer hospedagem estática.
